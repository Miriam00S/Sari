Przetestowany system operacyjny: Windows
Przetestowane przeglądarki: Chrome, Opera 
W dev toolsach sprawdzałam jak będzie wyglądać strona na różnych urządzeniach w tym telefonach tabletach
Aby zapewnić przyjemne dla użytkownika korzystanie ze strony dwie główne funkcje sortowanie i filtrowanie działają razem ze sobą. Możliwe jest sortowanie już wyfiltrowanych kanałów.

Do local storage dodałam również flafę o dark mode aby po przeładowaniu strony, był zachowyany preferowany motyw przez użytkownika.
